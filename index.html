Diseñando la Web para Todos

La accesibilidad web garantiza que las personas con discapacidad puedan percibir, comprender, navegar e interactuar con la web.

Claves de Accesibilidad Web

1. Lector de Pantalla (Audio)

Usamos etiquetas semánticas (`

`, `
`, `
`) y atributos `alt` en imágenes para que los programas de lectura en voz alta conviertan el texto en audio sin fallos.

2. Contraste y Colores

El fondo y el texto deben tener un alto contraste de color para facilitar la lectura a personas con baja visión o daltonismo.

3. Navegación por Teclado

Todos los elementos interactivos (botones, enlaces) deben ser accesibles usando únicamente la tecla Tab.
